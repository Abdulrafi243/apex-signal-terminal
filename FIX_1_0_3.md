# v1.0.3 — Live feed + late signal guard

## Fixed
- Dev WebSocket now connects directly to FastAPI on 127.0.0.1:8000 instead of racing through the Vite WS proxy.
- WebSocket cleanup no longer closes a socket while it is still CONNECTING.
- React StrictMode dev double-connect removed for this live-stream terminal.
- Binance REST candles retry 3 times and use a recent successful snapshot for up to 120 seconds during transient upstream/network failures.
- Chart candles no longer disappear when only the SMC overlay request fails.
- Overlay refresh interval increased to reduce upstream pressure.

## Trading safety: late-entry guard
- LIVE signals are emitted only when current price is inside the planned entry zone or within 0.20 ATR beyond it.
- Qualified setups that have not reached entry are REVIEW / WAIT ENTRY and do not notify.
- If price has extended too far past entry, the signal becomes NO_TRADE / MISSED.
- If TP1 was already touched after the setup formed, it becomes NO_TRADE / TP_ALREADY_REACHED, even if price later returns.
- Invalidated setups become NO_TRADE.
- Notifications fire only for actionable IN_ENTRY / NEAR_ENTRY A or A+ setups.
- Signal card now shows Current Price, Entry Status, and Action.
- Current signal polling reduced from 20s to 5s.
