# v1.0.9 — Fresh Trade Plan Invariant Fix

- Current Signal never displays historical Entry/SL/TP values when action is NO TRADE or WAIT FOR CONFIRMATION.
- Only Order Blocks from the last 12 bars can seed a current execution plan.
- Added final live trade-plan invariants:
  - LONG: SL below entry; TP1 < TP2 < TP3 and all above entry/current when live.
  - SHORT: SL above entry; TP1 > TP2 > TP3 and all below entry/current when live.
  - WAIT FOR ENTRY must still be ahead of current price in the intended direction.
- Any invariant violation forces NO TRADE and clears all executable levels.
- Dashboard explicitly shows decision refresh every 3 seconds while price is streamed by WebSocket.
