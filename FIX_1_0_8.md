# v1.0.8 — Professional Current-Decision Finalization

This release changes the terminal from a historical-setup status panel into a current-market decision engine.

## Decision output
The Current Signal panel now prioritizes exactly five actions:
- BUY NOW
- SELL NOW
- WAIT FOR ENTRY
- WAIT FOR CONFIRMATION
- NO TRADE

Historical labels such as MISSED, TP_ALREADY_REACHED, INVALIDATED, and STALE_SETUP remain internal diagnostics. They no longer become the primary user decision.

## 80+ signal policy
- Base execution threshold: 80/100
- 5M threshold: 84/100
- 1M threshold: 88/100
- 88–91: strong quality
- 92–100: A+ quality

The score is a confluence/quality score, not a guaranteed probability of profit.

## Professional core gate
A signal can tolerate one missing non-critical core technical confirmation. At least 3 of 4 must pass:
1. Higher-timeframe alignment
2. BOS/CHoCH structure confirmation
3. Liquidity event/sweep
4. Execution model using at least two of FVG / Order Block / qualified displacement

Secondary confluence improves the score but is not individually mandatory:
- FVG + Order Block overlap
- IFVG
- Premium/discount alignment
- OTE
- Session/kill-zone context
- Volume expansion
- Volatility expansion
- Clear news window

## Hard safety gates
No BUY NOW / SELL NOW is allowed when:
- market data is stale/unhealthy
- high-impact news lock is active
- risk/reward is below 1:2
- the entry is missed, invalidated, stale, or TP1 has already been reached
- the news feed is unverified (WAIT FOR CONFIRMATION)

## Notifications
Browser/Telegram/Webhook signal alerts now begin at 80+, but only for actionable BUY NOW / SELL NOW decisions with fresh entry status.
