# v1.0.5 Connectivity Hardening

- Added direct API fallback to `http://127.0.0.1:8000/api/v1` when the Vite `/api` proxy fails in local development.
- Added a 12-second API timeout with a clean `Backend is unreachable` message.
- Removed duplicate Vite config files; `vite.config.ts` is now the single source of truth.
- Pinned Vite to `127.0.0.1:5173` and proxy target to `127.0.0.1:8000`.
- Expanded backend CORS for both `localhost:5173` and `127.0.0.1:5173`.
- WebSocket local development now consistently targets `ws://127.0.0.1:8000`.
- Raw browser `Failed to fetch` is no longer shown to the user.
- Rate-limit caching from v1.0.4 and late-signal guard from v1.0.3 remain enabled.
