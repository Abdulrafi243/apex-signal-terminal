# Apex Signal Terminal v1.0.1 Hotfix

Fixes the browser error:
`Unexpected token '<', "<!doctype "... is not valid JSON`

Root cause: both `vite.config.ts` and a stale generated `vite.config.js` existed. The JS config did not proxy `/api` or `/ws`, so Vite returned `index.html` for API calls.

Changes:
- Added `/api` and `/ws` proxy to both Vite configs.
- Hardened API client to detect HTML/non-JSON responses and show a useful backend/proxy error.
- Hardened WebSocket URL construction for local dev, deployed HTTP, and deployed HTTPS.

Local startup:
1. Backend: `cd backend` then activate venv and run `uvicorn app.main:app --reload --port 8000`.
2. Frontend: from project root run `npm install` then `npm run dev`.
3. Open the Vite URL (usually http://localhost:5173).
4. Verify http://localhost:8000/api/v1/health returns JSON.
