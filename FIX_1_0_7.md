# v1.0.7 — False Backend-Unreachable / Analysis Latency Fix

- Fixed the contradictory state where the WebSocket chart was LIVE while the Current Signal card said "Backend is unreachable".
- The API client now probes `/health` before declaring a full backend outage.
- Analysis timeout now shows a temporary analysis-delay message instead of a false backend-down message.
- Current Signal keeps the last valid analysis visible during a temporary refresh failure.
- Production Health no longer labels the whole feed OFFLINE just because one health refresh failed.
- Higher-timeframe data loads concurrently instead of sequentially.
- Signal data-health reuses the candles already analyzed instead of creating another external market-data request.
- Binance REST candles use an 8-second short TTL while WebSocket keeps the active candle fresh.
- Reduced duplicate upstream requests and signal-analysis latency.
