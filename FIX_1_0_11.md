# v1.0.11 — Dynamic Current-Price Trade Plan

- Unified execution threshold remains 70/100.
- When a 70+ directional setup has fresh data but its historical OB/FVG entry is missed/stale/waiting, the engine creates a fresh NOW-plan anchored to the synchronized current quote.
- Dynamic stop placement blends ATR with the nearest recent structural swing and is constrained to a sensible ATR envelope.
- TP1/TP2/TP3 are rebuilt as 1R / 2R / 3R targets from the current entry plan.
- HIGH-impact or locked news still blocks execution.
- UNKNOWN news no longer blocks an otherwise valid technical signal; it remains visibly marked UNKNOWN and the decision reason warns that it is a technical-only signal.
- Adaptive core gate: score 70–79 requires 2/4 professional core confirmations; score 80+ requires 3/4.
- Existing plan sanity invariants remain enforced so LONG targets cannot appear below current/entry price and SHORT targets cannot appear above it.
